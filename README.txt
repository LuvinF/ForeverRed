JANNU — FOURTH MONTH ANNIVERSARY WEBSITE

1. Open index.html in a modern browser.
2. Password phrase:
   you are my home

3. To change the password:
   Open script.js and edit:
   const SECRET = "you are my home";

4. The counter starts from:
   1 June 2026

5. There are 24 hearts on the password screen.
   Every incorrect password makes one heart disappear.
   Correct password opens the site.

6. The website uses a paraphrased romantic line inspired by the feeling
   of Only You (1994), rather than reproducing a movie dialogue verbatim.

7. All text is editable directly inside index.html.

For best results, run it in Chrome, Edge, or Firefox with internet access
so the Google Fonts can load.


MUSIC
------
Put your legally obtained local copy of the song in this same folder as index.html and name it:
lady-in-red.mp3

The song starts after the correct password is entered. A small music button appears in the bottom-right corner for pause/play.
If your file has another name, change the filename in the <source> line in index.html.
